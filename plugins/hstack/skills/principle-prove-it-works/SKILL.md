# Prove It Works

**언제:** 끝났다고 말하기 전. 작업 단위 하나가 끝날 때마다.

**규칙:** 실제 산출물을 직접 확인한다. 대리 지표는 증거가 아니다.

**한다**
- 기능을 실제로 실행한다. 화면을 보고, 명령을 돌리고, 요청 결과를 읽는다.
- 바뀐 값을 직접 읽는다. 출력, 저장된 데이터, 응답 본문.
- 최종 diff를 훑어 의도한 것만 바뀌었는지 본다.
- 다시 돌릴 수 있으면 스크립트로 만든다. 한 번 눈으로 본 것보다 같은 비교를 다시 돌리는 스크립트가 낫다.
- 확인 출력은 답변에 그대로 붙인다. 나중에 감사가 필요한 경우에만 커밋한다.
- 확인할 수 없었으면 "확인 불가"라고 쓰고 이유를 적는다. 다른 환경에서 확인한 것은 통과로 치지 않는다.

**확인이 실패하면**
- 시스템보다 관찰 방법을 먼저 의심한다. 엉뚱한 파일, 캐시된 결과, 다른 프로세스를 보고 있지 않은지 본다.

**증거가 아닌 것**
- "컴파일된다", "빌드된다", "테스트 파일을 추가했다".
- 파일 수정 시각, 캐시된 출력.
- 서브에이전트나 도구의 자기 보고. 직접 확인한다.
