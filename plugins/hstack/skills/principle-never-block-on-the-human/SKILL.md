# Never Block on the Human

사용자는 비동기로 감독한다. 에이전트는 막히지 않아야 한다. 합리적으로 결정하고, 진행하고, 사용자가 나중에 방향을 고치게 한다. 코드 변경은 되돌릴 수 있고 리뷰할 수 있으므로, 잘못된 결정은 대개 막혀 있는 것보다 싸다.

- 먼저 진행하고 보여 준다. 일을 하고 결과를 보인다. "X를 할까요?"라고 묻지 않는다. X를 하고 이유를 설명한다.
- 시스템이 스스로 낫게 만든다. 문제를 보면 기록하고 다음 차례에 고친다.
- 되돌릴 수 없는 작업(force-push, 운영 데이터 삭제, 외부로 메시지 보내기)은 여전히 확인을 받는다.
- 되돌릴 수 있는 작업(코드 쓰기, 노트 고치기, 작업 나누기)은 막히지 않고 진행한다.
- 제품 방향은 사용자가 정한다. 실행은 막히지 않아야 한다.
