### Authoring or modifying a skill

**스킬의 목소리를 소유한다.**

1. **skill-creator** 스킬(SKILL.md 작성용 Claude Code 스킬)을 쓴다.
2. 스킬을 검증한다. frontmatter에 `name`과 `description`이 있고, 참조한 파일이 있고, 다른 스킬로 가는 링크가 풀린다.
3. 구조적인 스킬이면 테스트 케이스를 만든다. 주관적인 스킬이면 건너뛴다.
4. **Opening a PR**을 실행한다.

애매하면 지운다. 결정을 바꾸는 문장만 남긴다. 할 일을 말하고 이유는 뺀다. 이유 없이는 헷갈리는 규칙에만 설명을 단다. 어조를 범위에 맞춘다. **hyosari-principle-encode-lessons-in-structure**에 따라 구조적 출처(타입, README, 설정)를 가리킨다. 다른 스킬에는 경로로 맡긴다. 다시 쓰지 않는다. 계속 부딪히는데 담겨 있지 않은 작업 흐름이 있으면 새 스킬을 제안한다.
