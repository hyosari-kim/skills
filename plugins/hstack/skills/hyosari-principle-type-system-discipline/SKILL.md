# Type System Discipline

불가능한 상태, 어긋난 원시값, 처리하지 않은 변형을 컴파일러가 거부하게 만든다.

- **의미 있는 원시값에 브랜드를 붙인다.** 두 인자가 같은 원시 타입이지만 뜻이 다르면 각자 자기 타입을 준다. 만들 때 한 번 검증한다.
- **외부 데이터는 파싱하기 전까지 타입이 없다.** JSON, RPC 페이로드, CLI 인자, 설정, 환경 변수, 데이터베이스 행은 경계에서 타입 있는 모델을 돌려주는 파싱 함수를 거친다.
- **권위 있는 스키마에서 타입을 끌어낸다.** 스키마 파일이 형태를 소유하면 나란한 타입을 손으로 만들지 말고 그 스키마에서 끌어낸다.

언어별 문법은 그 언어용 스킬이 있으면 그것을 본다. 없으면 프로젝트의 `CLAUDE.md`와 기존 코드의 컨벤션을 따른다.
