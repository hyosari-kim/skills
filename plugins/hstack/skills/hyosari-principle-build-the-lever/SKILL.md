# Build the Lever

작업이 사소하지 않으면 손으로 하지 말고 그 일을 하는 도구(codemod, 스크립트, 생성기, 다시 돌릴 수 있는 확인)를 만든다. 기준은 반복 여부가 아니라 사소함이다. 뻔한 수정 몇 개일 때만 도구를 건너뛴다.

- 첫 단위는 손으로 하고, 그다음 도구를 만들어 그 단위에 다시 돌려 증명한다. 다시 돌려도 안전하게 만든다.
- 결정적인 도구가 여러 에이전트에 나눠 맡기기(fan-out)보다 낫다. 나눠 맡길 때는 방법, 확인 계약, 울타리를 위임받는 쪽이 읽기만 하고 고칠 수 없는 스킬 하나로 쓴다.
- 이 원칙을 적용하면 파일이 생긴다. diff에 스크립트, codemod, 생성기, 위임용 스킬이 없으면 적용하지 않은 것이다. 작업이 세션보다 오래 남으면 커밋한다.
- 일을 하거나 증명하는 가장 작은 스크립트를 만든다. 프레임워크는 만들지 않는다.
